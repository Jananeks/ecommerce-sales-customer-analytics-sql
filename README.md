# E-Commerce Sales & Customer Analytics using SQL

## 📌 Project Overview

A SQL-based e-commerce analytics project built using **Microsoft SQL Server** to analyze sales performance, customer behavior, product performance, payment trends, and order status.

The project demonstrates practical SQL skills and business-focused data analysis relevant to **Data Analyst and Business Analyst** roles.

## 🎯 Business Objectives

* Analyze overall sales and revenue performance
* Identify high-value and repeat customers
* Evaluate product and category performance
* Analyze orders by status
* Understand payment method usage
* Compare sales performance across cities
* Analyze monthly sales trends

## 📊 Key KPIs

* Total Customers
* Total Orders
* Total Revenue
* Average Order Value (AOV)
* Return Rate
* Revenue by Customer
* Revenue by Product
* Revenue by Category
* Revenue by City

## 🧠 SQL Skills Used

* SELECT, WHERE, ORDER BY, DISTINCT
* GROUP BY and HAVING
* Aggregate Functions: COUNT, SUM, AVG, MAX, MIN
* INNER JOIN and LEFT JOIN
* CASE Statements
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions: RANK, ROW_NUMBER, LAG, LEAD
* Running Totals using SUM() OVER()
* Date Functions
* Conditional Aggregation
* Primary Keys, Foreign Keys and Constraints

## 🔍 Key Analysis

## ▶️ How to Run

1. Create a database in SQL Server.
2. Run `sql/01_create_tables.sql` to create the tables.
3. Run `sql/02_insert_data.sql` to insert the sample data.
4. Run `sql/03_analysis_queries.sql` to perform the analysis.
